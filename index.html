Selected work at Tripledot

I built an on-call bot into our DevOps portal. When an alert lands in Slack, it pulls read-only data from Kubernetes, Prometheus, Loki and Argo CD across all 12 clusters, asks Claude on AWS Bedrock for the likely cause, and answers in the alert thread. It also records what each investigation cost.

A PHP bug with a CVSS score of 9.2 let anyone run code on a server without logging in. I scanned 107 repositories and moved 9 production services to a patched PHP, two of them old Symfony 3.4 apps. Before each rollout I ran the old and new images side by side and compared responses, database writes and queues. In the largest run, 266 of 266 checks matched.

Our Slack alert channels used to get about 48 notifications a day. I went through 72 Grafana alert rules in 10 channels, changed thresholds and routing so critical alerts get noticed, and added alerts for metrics going missing on any of 11 production clusters. Now there are a few a day.

I upgraded 10 EKS clusters from Kubernetes 1.34 to 1.36 with Terraform, one minor version at a time, and rolled the Redis Sentinel, MongoDB and MySQL workloads by hand. During the upgrade I found that Sentinel was announcing stale IP addresses, and fixed it.

A Rails game backend had been running on Docker Swarm with 7-year-old images. I moved it to EKS as a Helm release with Postgres 16, Redis, External Secrets and nightly backups to S3. I rehearsed the move on a copy of the 13 GB database first: the schema matched exactly, and the plan put downtime at about 20 minutes.

I replaced Percona PMM with Prometheus and Grafana for 66 MySQL and MongoDB databases on 8 clusters. That meant shared exporters, plus 17 dashboards and 14 alert rules ported from PMM and checked against live data.

I took our internal DevOps portal to production on Kubernetes, with SSO, IRSA, Helm and Argo CD. It reports AWS waste, rightsizing, Savings Plans coverage and pods without resource requests across 6 AWS accounts.

I deployed an AI service that compares video ad creatives. It runs on CPU with CLIP, ffmpeg and headless Chromium, with the API and the vision workers as separate deployments, Postgres with pgvector, nightly backups, Okta sign-in, and Terraform for ECR, S3, KMS and IRSA.

I built an EKS cluster for Unity GitHub Actions runners and moved the linter workflow of 36 game repositories onto it. Each repository gets a runner that matches its Unity version.

Other work: I onboard new services end to end, from Terraform (ECR, S3 and CloudFront, DynamoDB, IAM, secrets) to a Helm chart and an Argo CD app. I set up preview environments for every pull request with Argo CD ApplicationSet, and production deploys that ship only builds that passed CI. Runtime security runs on Sweet Security, and I triaged kernel CVEs across about 300 nodes. Secrets sync into Kubernetes from 1Password and AWS Secrets Manager. For the data and ML teams I run Airflow, MLflow, Feast and Redash. MySQL is backed up with XtraBackup, and a nightly job validates the 1.4 TB production backup. We moved from Terraform to OpenTofu, and I audited 12 clusters and 104 node groups for cost and security.
